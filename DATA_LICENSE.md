# Dataset attribution

The experiments use the public
[SMS Spam Multilingual Collection Dataset](https://huggingface.co/datasets/dbarbedillo/SMS_Spam_Multilingual_Collection_Dataset),
published by the upstream dataset provider under the GPL license.

No SMS text is redistributed in this code repository. Users should obtain the
dataset directly from the provider and comply with its license and terms. The
bilingual Indonesian-English corpus described separately in the manuscript is
also not included.
